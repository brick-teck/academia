# PULSE FITNESS — plano de implementação

Objetivo: apresentação comercial de uma rede fictícia, sem backend ou contratação efetiva. O briefing enviado pelo usuário é a especificação; execução completa já solicitada.

Tecnologia: HTML5, CSS3 e JavaScript puro, sem build. Todos os caminhos são relativos e o site abre por file://.

- [x] Identidade: Hero fotográfico cinematográfico, título condensado em três linhas, seleção de unidades na base. Preto #080808, superfície #171717, vermelho #E63946, branco #F7F7F7 e cinza #A1A1A1. Alternância de trechos claros e escuros para dar ritmo às seções.
- [x] Conteúdo: index.html contém landmarks e seções; data.js centraliza marca, unidades, períodos, modalidades, galeria, equipe, depoimentos e FAQ.
- [x] Interações: main.js compartilha renderização, seleção da unidade, grupos de botões, contatos, modal nativo acessível e lightbox com navegação por teclado. Unidade sincroniza Hero, planos e painel de localização; filtros independentes permitem comparar unidades.
- [x] Configuração: endereço e telefone vazios não geram Maps ou WhatsApp. Valores e pessoas são declarados fictícios. Convênios são exemplos configuráveis, sem logos oficiais.
- [x] Recursos: fotografias ilustrativas Unsplash otimizadas e baixadas; fontes Google Fonts locais. Sem dependência obrigatória de rede.
- [x] Verificação: teste da configuração, sintaxe JS, navegação real por file://, períodos e unidade, filtros, modal/Escape/foco, accordion, menu mobile, movimento reduzido e ausência de overflow em 320/375/430/768/1024/1440/1920 px.
- [x] Entrega: README de personalização/publicação, fontes e licenças documentadas, evidências de testes.

Limites: nenhuma promessa de saúde, coleta pessoal, credencial profissional ou parceria oficial. Publicação externa não faz parte do pedido de arquivos locais/GitHub Pages.
